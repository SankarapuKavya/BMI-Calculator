# BMI Calculator

A simple web application to calculate **Body Mass Index (BMI)** based on user input for weight and height.  
It displays the BMI value, category, and a reference table for quick understanding.


## Features
- Input weight (kg) and height (cm)
- Calculates BMI instantly
- Shows BMI category (Underweight, Normal, Overweight, Obese)
- Displays a reference table for ranges
- Responsive design with clean UI


## Tech Stack
- **HTML** – Structure
- **CSS** – Styling
- **JavaScript** – Logic & DOM manipulation
